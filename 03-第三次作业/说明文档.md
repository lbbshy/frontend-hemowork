# AI助教答疑平台 — 第三次作业说明文档

## 一、项目概述

本作业使用 **HTML + CSS + 原生 JavaScript** 设计并实现了一款「AI 助教答疑平台」，包含以下三个页面：

| 文件              | 说明                    |
| --------------- | --------------------- |
| `index.html`    | 答疑主页（提问 + 助教回答）       |
| `register.html` | 个性化注册页面               |
| `login.html`    | 登录页面（账号密码 / 短信验证码双模式） |

设计目标：在 VS Code 中借助 AI 工具通过多轮对话完成，**尽量使用 HTML5 表单增强**能力，实现个性化注册与登录。

***

## 二、页面效果说明

### 1. 答疑主页（index.html）

- 顶部标题「AI 助教答疑平台」+ 副标题「智能答疑 · 随时提问」
- 居中提问输入框 +「提问」按钮
- 助教回答卡片，左侧蓝色竖条标识，显示「助教回答」标签
- 提问后实时更新回答内容并累加问题计数

### 2. 注册页面（register.html）

个性化字段：用户名、邮箱、手机号、学号、院系（带输入建议）、密码、确认密码、头像选择、用户协议勾选。

### 3. 登录页面（login.html）

支持「账号密码」与「短信验证码」两种登录方式切换，含记住我、忘记密码、密码显示/隐藏、验证码倒计时等功能。

## 三、应用到的 HTML5 表单增强

### 3.1 新增 input 类型

| 类型                                    | 用途             | 所在字段          |
| ------------------------------------- | -------------- | ------------- |
| `type="email"`                        | 邮箱格式校验         | 注册-邮箱         |
| `type="tel"`                          | 电话号码           | 注册-手机号、登录-手机号 |
| `type="password"`                     | 密码（自动掩码）       | 注册密码、登录密码     |
| `type="text"` + `inputmode="numeric"` | 唤起数字键盘（学号、验证码） | 学号、验证码        |

### 3.2 表单属性（Attributes）

| 属性                        | 作用                  | 示例                                                       |
| ------------------------- | ------------------- | -------------------------------------------------------- |
| `required`                | 必填校验                | 几乎所有字段                                                   |
| `pattern`                 | 正则表达式校验             | 用户名 `^[A-Za-z0-9_]{3,20}$`、手机号 `^1[3-9]\d{9}$`           |
| `minlength` / `maxlength` | 最小/最大长度             | 密码 minlength=6、用户名 maxlength=20                          |
| `placeholder`             | 占位提示文本              | 各输入框                                                     |
| `autocomplete`            | 浏览器自动填充             | username / email / tel / new-password / current-password |
| `inputmode="numeric"`     | 移动端唤起数字键盘           | 学号、手机号、验证码                                               |
| `novalidate`              | 禁用浏览器默认校验气泡，改用自定义提示 | 注册/登录表单                                                  |
| `list` + `<datalist>`     | 输入建议下拉              | 院系列表                                                     |

### 3.3 约束验证 API（Constraint Validation API）

通过 JavaScript 调用原生校验能力，实现自定义错误提示：

```js
// 触发原生约束校验
if (!input.checkValidity()) { ... }

// 自定义校验信息（如两次密码不一致）
input.setCustomValidity('两次输入的密码不一致');
input.setCustomValidity('');   // 清除
```

### 3.4 CSS 校验伪类

```css
/* 校验通过（且非空）时绿色边框 */
input:valid:not(:placeholder-shown) { border-color: #22c55e; }

/* 校验失败时红色边框 + 浅红背景 */
input.invalid { border-color: #ef4444; background: #fef2f2; }
```

### 3.5 FormData API

提交时统一收集表单数据：

```js
const data = Object.fromEntries(new FormData(form).entries());
```

## 四、其他 HTML5 相关能力

## 五、关键交互实现

### 5.1 注册实时校验

- `input` 事件：边输入边校验
- `blur` 事件：失焦时校验
- 密码与确认密码联动校验
- 用户协议勾选状态校验

### 5.2 登录双模式

- Tab 切换「账号密码 / 短信验证码」
- 密码显示/隐藏切换按钮
- 验证码 60 秒倒计时
- 第三方登录入口（微信/QQ/GitHub）

### 5.3 答疑模拟

- 提问后动态更新回答内容
- 问题计数累加
- 输入长度校验（2-200 字符）
